Key findings

要点

  • 研究の主語が「学習法」から「AIに何をさせるか」へ移った。2026年は cs.AI (年換算 約61,000件) が cs.LG (約55,000件) を逆転する見込み。関心は学習アルゴリズムから、推論・計画・エージェントといったシステムの設計へ移っています。
  • 主役の手法はおよそ5年ごとに交代してきた。SVM (2007年ピーク) → CNN・RNN (2018年) → GAN (2019年) → 「深層学習」という言葉自体 (2021年) → 自己教師あり学習・GNN・連合学習 (2023年) → 拡散モデル (2025年)。ピークを過ぎた技術は消えるのではなく、当たり前の部品になって名前が書かれなくなります。
  • 2026年の三大テーマは LLM・推論・エージェント。要旨に含む割合は LLM 28.4%、推論 17.2%、エージェント 16.8%。
  • 最前線の研究対象は「モデル単体」から「モデル+ハーネス+環境」へ。2026年8〜9月の注目論文では、ハーネス、記憶、スキル、自己改善、on-policy 蒸留、世界モデルといった語が急増しています。いずれも1年前はほとんど見られませんでした。

Rise & fall

研究テーマの盛衰

要旨にキーワードを含む論文が、arXiv cs の全論文に占める割合。25テーマを時代ごとに4つのグループに分けています。

出典: arXiv 詳細検索 (abstract、cs+stat、クロスリスト含む、投稿年指定) の件数 ÷ arXiv cs の年間掲載件数。2026年は9月25日まで。「推論」「エージェント」「Transformer」は LLM 以前から別の意味 (論理推論、マルチエージェントシステム、変圧器) でも使われるため、水準よりも2024年以降の傾きに注目してください。

  • LLM は4年で 0.4% → 28.4%。20年で最大かつ最速のテーマ転換で、CNN のピーク (7.9%) の3.6倍の規模です。
  • 「深層学習」という言葉は2021年がピーク。廃れたのではなく、前提になりすぎて書かれなくなりました。CNN、RNN、GAN も同じ道をたどっています。
  • 強化学習が再び伸びている (2024年 4.0% → 2026年 7.4%)。LLM の推論力を鍛える手段 (RLVR、GRPO) として再評価されたためです。
  • 拡散モデルは2025年に頭打ち。関心はフローマッチングや世界モデルへ移りつつあります。

Latest submissions

最新投稿のトピック構成

cs.LG / cs.AI / cs.CL / cs.CV の9月の投稿タイトルを、2024年・2025年・2026年で比較しました。

  • エージェントが2年で約5倍 (2.2% → 5.8% → 10.9%)。タイトルでは LLM (15.6%) に次ぐ2位です。「LLM を使った X」から「エージェントとしての X」へ、論文の打ち出し方が変わっています。
  • ベンチマークと評価も伸びている (5.5% → 9.2%)。「何を、どう測るか」自体が研究の主題になりました。
  • 推論と強化学習は2025年がピーク。タイトルに掲げるテーマから、エージェント訓練の標準的な部品へと変わりつつあります。
Emerging terms

2026年に急浮上したキーワード

arXiv の9月新着タイトルと、Hugging Face Daily Papers の注目論文 (タイトル+要旨) での出現率。

「HF 全体」は 2026年8月1日〜9月25日に Daily Papers に取り上げられた 1,196本、「HF 上位200」は upvote 数の上位200本での出現率です。

  • ハーネス、自己改善、ツール利用は、注目度が高いほど出現率も高い (上位200本では全体の約2倍)。モデルを包む実行基盤 (ハーネス) を、モデル自身に設計・改善させる研究に関心が集まっています。
  • 記憶はタイトル比で1年に2倍以上。長時間動くエージェントには、文脈窓を超えて経験を保持する仕組みが必要になり、継続学習の研究が再び活発になっています。
  • on-policy 蒸留は1年で約10倍。強化学習で得た能力を小さなモデルへ移す、新しい事後学習の手法として定着しつつあります。

    Synthesis

    アカデミアの技術動向が進む6つの方向

    20年の長期トレンドと、最新投稿の短期シグナルを重ね合わせた結果です。

    2006〜2020年の AI 研究は「データから良い関数を学習する方法」を競い、2021年以降は「規模」を競ってきた。2025〜2026年のいまは、「自律的に考え・行動し・自己改善するシステムを、どう作り、どう測り、どう安全に保つか」を競う段階に入っている。

    今後1〜2年の注目点

    • エージェントの信頼性と評価:長時間タスクのベンチマーク (Terminal-Bench、SWE-bench 系) が飽和した後の、次の評価軸。
    • 継続学習と記憶:事前学習と推論の間にある「使いながら学ぶ」モデル。
    • 世界モデルと身体性の統合:動画生成、3D/4D、VLA が一つの世界モデルにまとまるか。
    • 自己改善ループの安全性:自己改善が広がるほど、アラインメント・レッドチーミング・解釈性の重要性が増す。
    • Transformer の後継:状態空間モデル、線形注意、拡散LM、潜在推論は現時点では 1% 前後の少数派だが、効率化の要請から研究が続いている。
    Method & caveats

    データと注意点

    • arXiv は査読前のプレプリントが中心で、学会に採択された論文とは一致しません。産業界の研究の一部や、非英語圏の研究は含まれにくい傾向があります。
    • キーワードの割合は傾向を見るための目安です。語の意味の揺れや、技術が普及して名前が書かれなくなる影響を受けます。分子 (cs+stat の要旨検索) と分母 (cs の年間件数) の範囲も完全には一致しません。
    • 2026年の値は9月25日までの集計です。年換算の値はその旨を明記しています。
    • Hugging Face Daily Papers はコミュニティが選んだサンプルで、生成AIやエージェントなど話題性の高い領域に偏っています。
    データ: arXiv (一覧ページ・詳細検索・月別一覧)、Hugging Face Daily Papers API。収集・分析・作図のスクリプトはリポジトリの scripts/、生データは data/ にあります。
